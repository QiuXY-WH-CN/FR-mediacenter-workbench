# 冯如学媒工作台操作手册

本手册适用于网页端与微信小程序 v3.0.0。配图来自隔离测试账号，展示界面位置，不含真实成员资料。

## 1. 修改姓名与头像

网页：点击左下角“个人资料”或右上角姓名。小程序：我的 → 姓名与头像。

1. 填写姓名，选择头像；系统自动裁切和压缩图片。
2. 点击“提交管理员审核”。此时公开姓名和头像仍显示原版本。
3. 管理员进入“成员与权限”→“姓名与头像审核”，检查申请并批准或退回。
4. 批准后两端刷新同步。退回后可重新申请；再次提交会替换尚未审核的申请。

修改密码仍在个人资料入口中单独操作，无需姓名与头像审批。

## 2. 新建活动与选择对接人

网页：工作概览或所有任务 → 新建活动。小程序：工作台 → 新建活动。

1. 选择空白日程或已有流程模板，填写名称与时间。
2. 在“需求方 / 对接人”展开部门，再选择部门成员。外部人员选择“其他 · 填写姓名”。未确定时可保持“未指定”。
3. 非全天活动须填写开始、结束时间。外派需求由办公室或管理员登记。
4. 使用模板时，为每个环节选择负责人和验收人。人员控件统一先选部门、再选成员。
5. 可填写活动云盘链接、积分和奖励说明，点击创建。

## 3. 我的任务与交付

1. “我的任务”按活动分组。点击大任务标题展开或折叠子任务。
2. 点击子任务查看负责人、验收人、截止时间及交付要求。
3. 接受任务；有课程或时间冲突时反馈说明，解决后恢复接活。
4. 提交前完成检查清单。若设置活动云盘，打开素材库上传后返回确认；成果链接需确认访问权限。
5. 验收人批准后任务完成并记积分；要求修改时补充成果重新提交。
6. 存在前序依赖的任务，等待所有前序任务通过验收后自动解锁。

## 4. 部门日历

部门筛选同时影响月历和时间轴。办公室用绿色，新媒体用琥珀色，视觉传达用蓝色，创意设计用紫色。点击任务或活动查看详情；点击日期查看当日截止任务。

网页时间轴支持横向浏览与缩放。有权负责人可拖动活动日期并确认改期，未完成任务随活动平移，已完成记录保留。

## 5. 查看组织与成员

所有已开通成员可进入“成员与权限”查看组织。点击网络图的部门筛选名单，点击成员节点查看资料，点击“显示全部”取消筛选。动画表达界面状态，连线仅表示组织归属。

管理员可管理成员权限并审核姓名头像。部门负责人可管理本部门普通成员，其他成员只有查看权限。待注册审核与停用账号按管理权限展示。

## 6. 成果与贡献

“成果与贡献”汇总成果归档及积分记录。归档条目可点击查看任务和成果链接。积分在任务验收通过后记账一次；其他奖励由负责人兑现。

工作概览底部展示全组织前五名贡献榜。相同积分按姓名排序，排名不授予额外权限。

## 7. 保存和复用流程模板

负责人进入“流程模板”创建流程，为环节填写部门、相对日期、截止时间、前序编号和交付要求。也可以在活动详情中“保存为模板”。使用模板创建活动后，后续修改模板不改变已创建活动。

## 8. 同步与连接

两端共用后端数据库。修改保存后刷新同步；列表定期更新。手机无法连接时检查“我的 → 连接设置”中的服务地址，并确认本机服务器和公网隧道在线。
