# 冯如书院学生媒体中心（学媒）SOP 流程项目

> 本文件是学媒 SOP 项目的总纲。项目目标：沉淀一套**可复用、可迭代、支持创新**的高效运作机制，让每年内容相近、时间相近的书院活动能够被提前规划、高质量交付。

## 一、项目背景与目标

冯如书院学生媒体中心（以下简称“学媒”）下设四个部门：办公室、新媒体运营部、视觉传达部、创意设计部。

书院每年的活动类型与时间安排大体相近，因此需要一套统一的运作机制：

- **可复用**：把流程、模板、规范沉淀下来，减少重复劳动；
- **支持创新**：在标准流程之上保留创作空间，鼓励内容创新；
- **高效协同**：一套时间表 + 一套日历 + 一个素材库，让四个部门步调一致。

## 二、部门职责与运作逻辑

### 1. 办公室（任务枢纽）

- 对外：与书院其他部门（学生学业支持中心“学支”、学生发展中心“学发”、学生艺术中心等）对接需求；
- 对内：把承接到的任务整合、分类，委派给新媒体运营部、视觉传达部、创意设计部；
- 定位：学媒内部的“总调度”，负责需求登记、派单、跟进与归档。

### 2. 新媒体运营部（文案 + 推送）

- 负责文案撰写与推送（推文）制作，**对时效要求高**；
- 常规做法：**提前写好推送文案**，活动结束后根据视觉传达部上传到素材库的图片、视频更新推送；
- 两种稿件来源：

| 稿件类型 | 流程 |
| --- | --- |
| 学媒自有项目 | 不对外接稿，文案自己写，自己选图 |
| 外派稿件（学支 / 学发 / 学生艺术中心等） | 先与办公室联络 → 办公室分配给新媒体运营部成员；对方提供素材，新媒体只负责排版 |

### 3. 视觉传达部（摄影 + 摄像 + 视频号）

- 负责书院各类活动的**院级摄影、摄像**；
- 负责“**冯如远航**”视频号的内容创作与运营；
- 摄影：遵循常规活动拍摄流程；
- 摄像：要求**拍丰富素材**，一般用于较大型活动。

### 4. 创意设计部（相对独立）

- 负责书院**文创**、各类活动的**视觉设计**（展板、海报等）；
- 配合其他部门的设计需求。

## 三、核心机制（详见 `00_机制与规范/`）

1. **内网云盘同步**：以项目根目录为唯一协作空间，所有成员同步到本地，按权限读写；
2. **素材库**：视觉传达部活动后及时上传图 / 视频，新媒体运营部据此更新推送；
3. **指导培训**：沉淀新人手册、模板、培训材料，降低上手成本；
4. **时间表 + 规范**：后续将年度活动时间表与相关规范填入 `01_时间表/`，并据此生成各部门日历。

## 四、本次建设任务清单

1. 设计运作机制（云盘同步、素材库、指导培训、时间表与规范）；
2. 按时间表为各部门制作 Excel 工作安排表；
3. 每个部门文件夹下创建部门手册（干什么、怎么办、如何配合、标准产出流程）；
4. 每个部门制作智能日历，并制作全学媒总日历。
