# 素材库

这里是学媒的公共素材资源池，存放活动照片、视频、源文件等。

## 目录约定

```text
素材库/
├── 2026-2027学年/       按“日期_活动名”建活动文件夹
│   ├── 20260925_开学典礼/
│   │   ├── 照片/
│   │   ├── 视频/
│   │   └── 源文件/
│   └── ...
└── 归档/                已完结活动 / 备份
```

## 使用要点

- **谁上传**：视觉传达部活动后上传（照片 48 小时内、视频 72 小时内）；创意设计部定稿后上传源文件；
- **谁使用**：新媒体运营部取图 / 视频做推送，其余部门按需取用；
- **怎么命名**：见 `00_机制与规范/03_素材库管理规范.md`。

> 模板（推送 / 海报 / 展板）不放在这里，统一放 `培训与模板/`。
