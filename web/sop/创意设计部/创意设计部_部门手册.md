# 创意设计部 部门手册

## 一、我们是干什么的

创意设计部相对独立，负责书院的**文创**、各类活动的**视觉设计**（展板、海报、主视觉等），并配合其他部门的设计需求。简单说——**学媒的“门面”，由我们来设计**。

## 二、核心职责

1. 书院文创产品设计；
2. 活动视觉设计（展板、海报、横幅、主视觉、节目单等）；
3. 配合新媒体（封面 / 配图）、视觉（视频包装）、办公室（活动物料）的设计需求。

## 三、标准作业流程（怎么办）

### 3.1 接需求

1. 从办公室或其他部门接收设计需求（brief）；
2. 确认：用途、尺寸、风格、文案、截止时间。

### 3.2 设计

1. 出 1–2 版初稿（草稿）；
2. 提交需求方 / 办公室评审；
3. 按反馈修改，定稿。

### 3.3 交付

1. 交付：导出图（按要求尺寸 / 格式）+ 可编辑源文件；
2. 源文件归档到 `素材库/归档/`。

### 3.4 文创

1. 选题 / 提案 → 设计 → 打样确认 → 对接制作 → 上架 / 发放。

## 四、与其他部门如何配合

| 对方 | 配合方式 |
| --- | --- |
| 办公室 | 接活动物料 / 文创需求，明确 brief 与交付时间 |
| 新媒体运营部 | 提供推送封面、配图、长图等 |
| 视觉传达部 | 提供视频封面、包装设计，配合其拍摄需求 |

## 五、标准产出与交付物

- 设计源文件（可编辑）
- 导出成品图（展板 / 海报 / 封面等）
- 文创成品或打样

## 六、常用模板与位置

- 海报 / 展板模板：`培训与模板/`
- 工作安排表：`创意设计部/创意设计部_工作安排表.xlsx`
- 智能日历：`创意设计部/创意设计部_智能日历.ics`

## 七、常见问题（FAQ）

**Q：需求方描述不清？**
A：要求补齐 brief（用途 / 尺寸 / 风格 / 文案 / 截止），避免反复改稿。

**Q：工期太紧？**
A：与办公室 / 需求方协商优先级，必要时先给简版，后补精修。
