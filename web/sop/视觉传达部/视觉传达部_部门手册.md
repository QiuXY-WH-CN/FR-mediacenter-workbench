# 视觉传达部 部门手册

## 一、我们是干什么的

视觉传达部负责书院各类活动的**院级摄影、摄像**，以及“**冯如远航**”视频号的内容创作与运营。简单说——**活动的影像，由我们记录和输出**。

## 二、核心职责

1. 活动摄影（常规活动拍摄流程）；
2. 活动摄像（拍丰富素材，一般用于较大活动）；
3. 素材整理与上传素材库；
4. “冯如远航”视频号内容创作与运营。

## 三、标准作业流程（怎么办）

### 3.1 接单与准备

1. 从办公室接收拍摄需求（活动、时间、地点、拍摄重点）；
2. 领取 / 检查设备（相机、电池、存储卡、稳定器等）；
3. 提前到场踩点，明确机位。

### 3.2 现场拍摄

- **摄影**：遵循常规活动拍摄流程，重点拍主舞台、嘉宾、观众反应、关键环节；
- **摄像**：拍**丰富素材**——多机位、多景别、长镜头 + 细节，方便后期剪辑。

### 3.3 后期与交付

1. 选片 / 粗剪，删除模糊、重复素材；
2. 按规范命名，上传素材库（`素材库/年度/日期_活动名/`）：
   - 照片：活动后 **48 小时**内；
   - 视频素材：活动后 **72 小时**内；
3. 需要成片的，按期交付。

### 3.4 视频号运营

1. 选题策划 → 拍摄 → 剪辑 → 审核 → 发布 → 数据复盘；
2. 按排期稳定更新，保持账号活跃。

## 四、与其他部门如何配合

| 对方 | 配合方式 |
| --- | --- |
| 办公室 | 接收拍摄派单，明确活动级别（是否需要摄像）与拍摄重点 |
| 新媒体运营部 | 活动后及时上传素材库，供新媒体更新推送；新媒体反馈所需画面 |
| 创意设计部 | 视频封面、包装字体等设计需求，向创意设计部提 brief |

## 五、标准产出与交付物

- 活动照片包（精选）
- 视频素材 / 成片
- 视频号内容
- 素材库归档

## 七、常见问题（FAQ）

**Q：设备不够或坏了怎么办？**
A：提前向办公室报备，协调借用或调整拍摄方案。

**Q：同时多场活动撞期？**
A：提前与办公室沟通优先级，必要时招募机动成员支援。
