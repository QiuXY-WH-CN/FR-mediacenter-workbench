# 新媒体运营部 部门手册

## 一、我们是干什么的

新媒体运营部负责学媒的**文案与推送**，是把活动“讲出去”的人。**对时效要求高**，核心心法：**提前预写文案，活动后换图更新，快速发布**。

## 二、核心职责

1. 撰写文案（活动预告、回顾、专题）；
2. 推送排版与发布；
3. 学媒自有项目的选题策划；
4. 与外派需求方对接排版需求。

## 三、标准作业流程（怎么办）

### 3.1 先分清稿件来源

| 类型 | 流程 |
| --- | --- |
| 学媒自有项目 | 不对外接稿；自己写稿、自己选图 |
| 外派稿件（学支 / 学发 / 艺术中心等） | 先与办公室联络 → 办公室分配负责人 → 对方给素材 → 新媒体只做排版 |

### 3.2 标准生产流程

1. **接单 / 选题**：办公室派单，或自定选题并报备；
2. **预写文案**：活动前完成文案主体（时间、地点、背景、流程）；
3. **排版**：套用推送模板排版；
4. **审核**：提交部长 / 办公室审核（文字、图片版权、事实核对）；
5. **发布**：按排期发布；
6. **更新**：活动结束后，根据视觉传达部上传到素材库的图 / 视频更新推送（换图、补现场）；
7. **复盘**：记录阅读量、反馈，沉淀经验。

### 3.3 时间节点（重要）

| 节点 | 要求 |
| --- | --- |
| 活动前 | 完成文案预写与初排 |
| 活动结束 | 视觉上传素材后 **24 小时内**完成更新发布 |
| 外派稿 | 对方交齐素材后按约定时限排版交付 |

## 四、与其他部门如何配合

| 对方 | 配合方式 |
| --- | --- |
| 办公室 | 外派稿由办公室统一派单；发布前办公室协助审核把关 |
| 视觉传达部 | 视觉在活动后上传素材库，新媒体从中取图 / 视频 |
| 创意设计部 | 推送封面、配图、长图等设计需求，向创意设计部提 brief |

## 五、标准产出与交付物

- 推文（发布链接 + 文案稿）
- 排版成品截图 / 预览
- 选题与排期表

## 七、常见问题（FAQ）

**Q：活动临时改期，预写文案怎么办？**
A：保留框架，只改时间 / 地点字段，不推翻重写。

**Q：素材库没有可用图怎么办？**
A：先与视觉传达部沟通，必要时用往期素材或创意设计部做的封面图兜底，同时反馈办公室。
