# 冯如学媒知识库

本知识库适用于 v1.0.5 的网页、微信小程序与多端 APP。业务流程由同一后端维护；不同设备的操作入口与触控方式有所不同。

小程序新人可在“我的 → 知识库 → 工作台操作手册 · 图解”阅读第 12 节的逐步使用手册，包含登录、验证码、记住选项、四个导航入口、多人成果验收、代交付、归档、层级日历、圆形头像裁剪、外观与字号、本机安全中心、在线状态和连接排障。配图已替换为 2026 年 10 月的当前原生模拟器画面，全部采用独立无网络匿名样例；不包含真实账号、成员或业务资料，源码中的图片也可离线查阅。

## 从哪里开始

桌面网页通过左侧导航进入工作页面，个人中心在左下角。手机网页与小程序／APP 的底部保留“工作台、任务、日历、我的”；所有任务、流程模板、组织与成员、知识库等其他入口归入“我的”。原先右上角的重复账号入口已合并。

个人中心用独立的部门和工作空间信息展示归属。个人设置在“通用、外观、账号与安全”中完成。切换 English 只翻译界面，“冯如学媒”品牌、成员姓名、任务内容和知识库正文保留原文。

## 团队怎么协作

学媒下设办公室、新媒体运营部、视觉传达部和创意设计部。办公室登记需求、派单、跟进与归档；新媒体运营部负责文案、推送和排版发布；视觉传达部负责摄影、摄像及视频内容；创意设计部负责文创、海报、展板等设计。

全体协作用于跨部门项目；切换部门工作空间后聚焦该部门内部日程和人员分配，并采用对应主题色。切换工作空间只是选择工作范围，不会增加账号权限。无权查看的日程和管理操作仍由后端限制。

## 一次活动如何完成

1. 办公室登记活动，明确时间、地点、需求方和交付目标。
2. 有权限的负责人创建活动，选择流程模板或空白日程。
3. 建立分任务，明确部门、负责人、验收人、截止时间、优先级和交付要求。
4. 成员接单；存在课程或时间冲突时及时说明，确认调整后恢复工作。
5. 成员完成检查清单、上传素材并提交成果链接；验收人批准或要求修改。
6. 完成后归档到活动素材库，成熟流程保存为模板。

大任务组织活动，分任务承担具体交付。列表和日历按这一层级显示。未完成任务优先，截止时间越早越靠前；同截止时间优先级高的靠前。仅标记高优先级的项目会出现在“急急急”，不能依靠这一栏代替截止时间管理。

## 日历和排期

月历日期用于选择当日安排；选中后查看该日的大任务和分任务。小程序／APP 在月份格子内提供任务提示，并在下方展开当日层级列表，手机上优先采用点选和滑动查看。部门筛选与当前工作空间共同决定可见范围。

网页时间轴可横向浏览和缩放；有权限的负责人通过任务／活动的改期交互调整排期并确认。日期数字、导航和状态标签不参与文本拖拽，避免触控误选或拖进浏览器搜索；任务正文、成果说明和知识库仍保留复制能力。

## 素材与成果

照片精选通常在活动后 48 小时内上传，视频素材在 72 小时内上传，设计源文件在定稿后 3 天内归档；实际截止时间以负责人确认的任务排期为准。文件命名为 `日期_活动名_内容_序号`。

活动可以配置统一素材库链接。先上传、再确认交付，并检查验收人能打开成果链接。任务验收归档后为最终执行人记录积分，多人共同执行时分摊固定总额；其他奖励由负责人兑现。模板只影响新建活动，不回写已经创建的任务。

## 组织与成员

“组织架构图”展示部门和成员的归属与层级。部门气泡持续漂浮，展开后显示成员气泡。桌面使用悬停或点击查看资料；移动端点选资料、在空白处关闭。管理操作按角色和部门范围展示，组织图的连线与动画本身不授予权限。

姓名与头像变更按页面提示提交审核，通过后公开资料才更新。账号与安全设置包含改密、切换账号、退出和注销申请；注销走审核流程，不能替代活动资料归档。

## 阅读与外观

“通用”提供中文／English 和 85%—135% 系统字号。调整字号可以先预览，保存后应用到当前账号的所有页面；其他已登录设备刷新获取。较大字号下，卡片与菜单换行，手机保持单列和可滚动内容。

“外观”提供自定义强调色、白／黑／跟随系统，以及“开启动效”总开关。关闭总开关会暂停粒子和组织漂浮等动画。已移除无明显作用的“紧凑布局”和“跟随系统减少动态效果”选项。

## 粒子工作室

在“外观”选择粒子样式，再调运动、触点和光色。样式可固定、随机或定时轮换；仅定时轮换时显示间隔。网页提供局部画布预览，小程序／APP 在设置页即时预览；保存后同步账号参数。

粒子主要沿页面边缘移动，覆盖网页导航区域并保持中心更淡。可调整边缘分布比例。画布不拦截点击；触点响应与页面滚动、按钮操作同时进行。

可选六款渐变预设：极光流萤、樱花微风、银河星尘、森林萤火、海盐蓝绿、日落流金。预设同时调整颜色和部分运动参数；选定后仍可修改。颜色模式支持渐变、动态变色、单色或跟随主题。

碰撞作用于粒子之间和画布边界；速度、二维引力、阻尼、弹性、生命周期和随机性改变轨迹。透明度、亮度与闪烁分别控制显隐、明暗和周期变化。鼠标／触点可设置排斥、吸引或关闭，并调力度与作用范围。详细范围和操作见《工作台操作手册》。

设置设计参考 [Wallpaper Engine 的运动与碰撞 Operators](https://docs.wallpaperengine.io/en/scene/particles/component/operator.html) 和 [Control Points](https://docs.wallpaperengine.io/en/scene/particles/component/control_point.html)，在本工作台实现二维交互效果；不提供 Wallpaper Engine 工程导入、三维模型碰撞或完整编辑器兼容。

## 隐私与同步

账号设置由服务器按当前登录账号保存，包括主题、语言、字号及粒子参数。鼠标和触控坐标只存在于本机运行内存中，不上传、不持久化、不写日志；改变参数也不上传屏幕截图。

好友转发和朋友圈分享提供小程序入口，不携带任务、成员资料、会话或邀请码；接收者仍须按正常流程登录并通过权限校验。请勿把含真实成员信息的界面截图、导出的数据库或部署凭据发布到公开仓库。

清除缓存只处理本机缓存，保留账号登录和服务器任务。退出、换账号应通过个人中心完成。手机连接失败时在“我的 → 连接设置”核对服务地址；先检查本机源站，再检查公网隧道，不要重复创建账号或初始化数据库。

源码同步不代表客户端自动升级。已安装 APP 需要重新构建、安装；已发布小程序需要另行上传和发布，本轮未上传。知识库是构建时打包的登录后快照，更新文档后需要重新构建服务。

## v1.0.5 小更新 · 登录与在线状态

登录页新增默认不勾选的“记住账号密码”。勾选后记住账号并保持登录，最长 30 天；会话失效、管理员重置密码、账号封存或锁定仍会阻止登录。保存的表单资料不会自动发起登录，不绕过图形验证码、冷却或十次锁定。取消记住选项或清除记住信息后移除本机主动保存的登录资料；退出只撤销会话，借用设备应先清除记住信息再退出。网页浏览器密码管理器的记录需要在浏览器设置单独删除。

网页只保存用户名与选项，密码由浏览器密码管理器接管，不写入普通网页存储。小程序／APP 仅在微信加密存储接口可用时保存加密密码；不支持时显示提示，只记住账号并保持登录。未勾选时登录凭据仅保留在当前进程内存。改密、切换账号和退出按当前账号处理，迟到的请求不能回填上一账号。

“组织与成员”的成员圆泡、成员名单和个人资料卡使用绿色“在线”或灰色“离线”。状态只表示该账号有没有有效前台心跳：约每 25 秒更新，90 秒后过期，退到后台主动离线；一个账号有多个设备时，任一设备仍在前台即可在线。不展示最后上线时间、具体设备、轨迹或定位，权限范围内的成员才能查看。断网或系统限制可能延迟状态，不能用它证明是否已读或是否在工作。

## 小程序审核前的账号封存

当前临时审核模式只允许初始管理员登录与显示，其余账号暂不可用、不可见。初始管理员使用“审核管理员 / review_admin”安全别名，原登录凭据不变；不展示原姓名、账号和头像。全部历史用户内容与审核空间隔离，涵盖成员、资料、设置、活动日程、任务、模板、成果、积分、通知、申请及历史日志统计。原始账号状态和业务记录保留在受保护的完整 SQLite 本机备份中，不删除或覆盖。初始管理员仍不属于部门、不可被派单，审核空间没有可派执行人时不要给管理员自派或重新初始化。

审核期间登录选项改为“保持登录”，仅保持最长 30 天会话，不读取、预填或保存任何用户名密码；注册入口隐藏。不记录访问统计，统计页面为空，微信绑定接口暂时关闭。即使回退到旧程序，也不得通过旧接口取回封存内容。审核管理员仅可读取干净审核空间和匿名使用图解；所有历史内容需要维护者明确恢复后才重新可用。

维护者使用受保护的本机备份和独立审核空间完成暂存，审核通过后再恢复原始账号状态与协作空间。密码、数据库、封存清单和恢复材料均不公开，不进入 GitHub、手册、截图或小程序包。恢复由维护者在 `web` 目录执行 `node scripts/account-review.mjs restore`，不要通过新增同名账号代替恢复。

封存或恢复必须先停止当前工作区源服务；脚本在 8766 端口仍运行时拒绝切换，防止同时写入。恢复须等审核通过且用户明确要求后执行。在 `web` 目录的 PowerShell 中：

```powershell
. ./scripts/start-services.ps1
Stop-WorkbenchOrigin -WebRoot (Get-Location).Path
node scripts/account-review.mjs restore
Start-WorkbenchServices -WebRoot (Get-Location).Path -IncludeTunnel
```

首次封存使用同样的停止／启动流程，将中间命令替换为 `node scripts/account-review.mjs seal`。停止脚本先核验本工作区进程身份；不要手工结束未知进程、复制生产数据库到公开目录或用旧备份覆盖当前数据库。

本次是 v1.0.5 的小更新，覆盖最新部署与手册，保留已有补丁命名规则。手册正常协作截图中的“示例”成员和活动为离线样例，审核期实际页面应为空列表或仅初始管理员。


## v1.0.5 · 组织、任务与本机安全

组织架构图使用圆形节点、阻尼弹簧和圆形碰撞约束。部门展开、查看资料或固定资料卡时，图中的母气泡和子气泡继续运动。拖动任意部门或成员，只持有该节点；松开后带有惯性，速度逐渐衰减。根节点代表冯如学媒。桌面滚轮、缩放按钮和手机双指缩放调整视图，空白处拖动平移；“居中”恢复视图。开关动效或本机安全外观会暂停运动。动画位置、缩放及触点都只在本机计算。

初始管理员不属于任何部门，不出现在执行人选单，也不参与新任务派单；可作为验收监督。旧版本已派给初始管理员的未完成任务保留，并提示重新分配，不删除任务或历史积分。人员二级菜单在姓名旁显示职位，执行人与验收人均可多选。

| 操作 | 管理员 | 部门负责人 | 普通成员 |
| --- | --- | --- | --- |
| 编辑未完成任务名称、截止时间、要求、检查项、前序、优先级与奖励、执行及验收名单 | 可以 | 自己创建活动或本部门负责的任务 | 不可以 |
| 将本人负责的未完成工作转派给下属 | 可调整分工 | 仅本部门普通成员；原共同执行人继续保留 | 不可以 |
| 代交付与直接归档 | 所有任务，包括本人和部门负责人 | 全部执行人均为本部门普通成员的任务 | 不可以 |
| 验收 | 所有任务 | 被指定为验收人或符合代归档权限 | 被指定为验收人 |

转派会重新确认任务，清理旧提交草稿，保留任务总积分与验收人员。任务完成后，总积分在最终共同执行人间均分，精确到百分之一；余量分给名单靠前者，不提高总额。归档重复提交不会重复发分，已完成任务不可重新编辑分工。代交付和归档同样需要完成全部核对项、成果说明以及素材上传和链接确认，前序任务必须已完成；记录实际操作人。

“所有任务”新增“归档”。已完成分任务及完成活动可在这里查看；原日历与时间轴保留灰色任务，不因归档被删除。调整活动日期只移动未完成任务。共同执行或验收名单中的任何人尚有未完成工作时，都必须先交接才能批准注销。

跨部门共同执行的任务，在任意执行人所属部门的日历筛选中均显示，归档后仍保留；部门内部无分任务的空白日程也会显示。筛选仅使用当前账号已有权限的快照，不会获取其他部门的私有任务。

上传头像后，在本机拖动、缩放与圆形预览内调整取景，明确点击使用头像后才写入申请草稿；取消不上传。提交的是去掉原文件与 EXIF 的压缩正方形 JPEG，所有端以圆形展示，姓名和头像仍需管理员审核。解码期间切换账号或离开页面会丢弃旧结果。

## 安全中心与自我修复

入口：个人中心 → 设置 → 安全中心。网页、小程序和 APP 显示本机存储、界面/画布能力、展示配置、当前版本及固定错误码摘要；这里不检查或显示服务器 CPU、数据库、服务器在线率等健康信息。打开本机诊断不上传资料、错误原文、请求地址、任务或触控轨迹。

- 启动时规范化展示配置，损坏的展示缓存自动清理，无法使用的存储改用内存。
- 画布或界面异常时采用安全外观，暂停粒子和组织浮动，保留可操作入口。
- 同一次登录已经读取的内容，在暂时失去连接时可只读浏览。自动读取最多重试三次；写操作和密码提交不自动重复。
- 重新登录、退出、换号或权限撤销时清除旧内存快照，迟到响应不得恢复前一账号的数据；业务内容不持久化为跨账号离线缓存。
- 可修复展示缓存、重置本机颜色与字号、重新打开/重新检查界面、复制脱敏诊断。不会删除账号、任务、登录凭据或连接设置，也不会自动修改账号在服务器保存的外观。

网页重新检查需要读取最新工作状态；小程序/APP 的安全中心本机检查与修复动作本身无需网络，恢复业务编辑需回到工作页面刷新。手动保存外观后重新使用账号设置。

## 密码保护与管理员找回

密码保护按账号计数，换 IP 也不能绕过。成功密码登录或正式使用重置链接后清零；在此前的连续密码错误累计达到第三次时，要求一次性图形验证码并进入冷却。

| 密码错误次数 | 处理 |
| --- | --- |
| 1—2 | 提示用户名或密码不正确 |
| 3 | 冷却 30 秒；此后登录需要 5 位图形验证码 |
| 4、5、6、7 | 分别冷却 60 秒、2 分钟、4 分钟、8 分钟 |
| 8—9 | 冷却 15 分钟 |
| 10 | 锁定密码登录，必须联系管理员生成重置链接 |

验证码限当前账号及连接来源，120 秒有效、使用一次即失效，可点击图片刷新。未通过验证码或冷却期间被拒的请求不继续增加密码错误次数。还有独立请求频率限制和并发比较保护。锁定后正确密码、刷新页面或等待都不能解锁，微信绑定登录也不能绕过锁定。

管理员通过成员管理生成 24 小时有效、仅一次使用的重置链接，单独交给本人。锁定账号须由管理员重置，部门负责人不能解除此锁定。正式重置会使旧登录会话失效。另一名管理员可为初始管理员生成链接；只有初始管理员时，可由有本机文件权限的运维人员运行：

```powershell
cd web
node scripts/admin-reset.mjs --username ADMIN_USERNAME --issue
```

链接仅写入被 Git 忽略且公网不可读取的 `.local/admin-reset-link.txt`，不会在控制台打印凭据；使用链接前密码与锁定保持原状。

## 站长统计与隐私

仅管理员可读取和维护站长统计。提供 1/7/14 天网页范围、原生 14 天统计、访问趋势、访客日、请求/异常/风险数量、全球访问示意图、脱敏访问网段、请求及错误日志、筛选和固定修复建议。国家位置只采用可信边缘来源，没有来源则标“未知”，地图点为国家级示意，不是精确坐标或边界。

IPv4 仅展示 /24 网段，IPv6 仅展示 /48 网段。访客按每日加盐哈希去重，跨日合计叫“访客日”，不等于跨日独立人数。统计不保存完整 IP、账号映射、Cookie、验证码答案、密码、请求正文或查询参数，不调用第三方定位服务，不上传本机诊断。风险信号用于排查，不自动判定攻击。

保留最近 14 天，最多 1200 条请求日志和 6000 条访客记录。“维护统计”清理过期/超量记录；“清除访问与诊断统计”经确认后清理统计，不删除业务账号、活动或任务。处理错误可先检查本机安全中心和当前输入，管理员再核对发布；不要为解决报错而放宽权限或暴露私有文件。

## 发布回退与多端同步

版本按 v1.0.5、v1.0.6 等补丁号递增。启动更新先构建并备份，再仅停止经过身份核验的本工作区进程；新构建启动失败时，恢复上一已验证程序。手动回退：

```powershell
cd web
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/rollback-local.ps1
```

回退程序不回滚数据库。退回旧代码时只允许已有登录会话只读浏览和退出，禁止业务修改与新密码登录，防止旧版本绕过新权限或密码保护。修复后重新运行正常启动脚本即可恢复新版。所有自动恢复有次数限制，失败时仍保留手动入口。

网页需重新构建与重启；公网通过同一固定隧道访问，并检查实际 JS/CSS 和版本。APP/小程序源代码共用接口与模型，原生版本 1.0.5 / 构建号 105；已安装 APP 需要重新构建安装，小程序需编译并发布后真机生效。本轮不上传微信小程序。

设计参考：[Apple 阻尼弹簧](https://developer.apple.com/documentation/swiftui/spring)、[OWASP 身份验证防护](https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html)、[OWASP 凭据攻击防护](https://cheatsheetseries.owasp.org/cheatsheets/Credential_Stuffing_Prevention_Cheat_Sheet.html)。

发布前检查生产和开发依赖，修复已知依赖漏洞；当前 ORM 为 0.45.2，间接 esbuild 为 0.25.11。依赖扫描不能替代权限、隐私和运行测试，后续补丁仍需复查。
