# 冯如书院学生媒体中心 SOP 流程项目

欢迎来到学媒 SOP 项目。这里沉淀了学媒（办公室、新媒体运营部、视觉传达部、创意设计部）的高效运作机制、时间表、部门手册与智能日历，目标是让每年“内容相近、时间相近”的书院活动能够被**提前规划、高效完成、持续复用**。

## 一、这是什么？

- **一个盘子**：项目根目录就是协作空间，通过内网云盘同步给每位成员；
- **一套标准**：流程、命名、模板、规范，见 `00_机制与规范/`；
- **一个时钟**：年度活动时间表，见 `01_时间表/`，这是所有安排的数据源；
- **一套日历**：每个部门的智能日历 + 全学媒总日历，见 `02_总日历/` 和各 `部门文件夹/`；
- **一份手册**：每个部门“干什么、怎么办、如何配合、标准产出流程”，见各 `部门文件夹/部门_部门手册.md`。

### 素材库

素材库是学媒的公共素材资源池，存放活动照片、视频和源文件等。

```text
素材库/
├── 2026-2027学年/       按“日期_活动名”建活动文件夹
│   ├── 20260925_开学典礼/
│   │   ├── 照片/
│   │   ├── 视频/
│   │   └── 源文件/
│   └── ...
└── 归档/                已完结活动 / 备份
```

- 视觉传达部活动后上传照片（48 小时内）和视频（72 小时内）；创意设计部定稿后上传源文件。
- 新媒体运营部可取用照片和视频，其他部门按需取用。
- 素材命名遵循 `00_机制与规范/03_素材库管理规范.md`；推送、海报和展板模板统一放在 `培训与模板/`。

### 培训与模板

这里集中存放新人培训材料、各类模板和活动复盘记录。

```text
培训与模板/
├── 新人培训/        新成员入职培训材料
├── 推送模板/        新媒体排版模板
├── 海报模板/        创意设计部海报模板
├── 展板模板/        创意设计部展板模板
└── 复盘/            活动复盘记录
```

- 办公室维护需求登记表、任务分派表、新人培训与复盘记录。
- 新媒体运营部维护推送模板；创意设计部维护海报和展板模板。
- 详细培训体系见 `00_机制与规范/04_指导培训体系.md`。

## 三、快速上手（新人请看）

1. 先读本文件与 `00_机制与规范/01_学媒运作机制总设计.md`；
2. 到自己部门的文件夹，读 `部门_部门手册.md`；
3. 打开 `部门_工作安排表.xlsx` 查看本年度工作安排；
4. 导入 `部门_智能日历.ics` 到手机 / 电脑日历，查看自己的任务；
5. 需要素材去 `素材库/`，需要模板去 `培训与模板/`。

## 四、如何更新（办公室 / 维护者请看）

1. 修改 `01_时间表/schedule.csv`（用 Excel / WPS 打开编辑后另存为 CSV）；
2. 运行 `03_脚本/一键更新日历.bat`（或执行 `python 生成日历.py`）；
3. 云盘同步后，成员重新导入 `.ics` 或刷新日历订阅即可看到最新安排。

> 说明：当前 `schedule.csv` 与各 Excel 中的时间为**示例时间表**（按 2026–2027 学年常见书院活动编排），用于展示结构与排版。请办公室根据学校 / 书院正式校历替换为真实时间后重新生成。
