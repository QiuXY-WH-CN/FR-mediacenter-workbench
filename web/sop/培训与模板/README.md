# 培训与模板

这里是学媒的“知识库”：新人培训材料、各类模板、复盘记录。

## 目录约定

```text
培训与模板/
├── 新人培训/        新成员入职培训材料
├── 推送模板/        新媒体排版模板
├── 海报模板/        创意设计部海报模板
├── 展板模板/        创意设计部展板模板
└── 复盘/            活动复盘记录
```

## 使用要点

- **办公室**：维护需求登记表、任务分派表、新人培训与复盘记录；
- **新媒体运营部**：推送模板放 `推送模板/`；
- **创意设计部**：海报 / 展板模板放对应目录。

> 详细培训体系见 `00_机制与规范/04_指导培训体系.md`。
