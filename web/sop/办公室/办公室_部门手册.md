# 办公室 部门手册

## 一、我们是干什么的

办公室是学媒的**任务枢纽和总调度**：对外对接书院其他部门的需求，对内把任务整合、分类、派给三个业务部门，并负责跟进、验收与归档。简单说——**别人找学媒办事，先找办公室；学媒内部谁干什么，办公室来安排**。

## 二、核心职责

1. **需求对接**：与学支、学发、学生艺术中心等书院部门保持联系，接收稿件 / 拍摄 / 设计需求；
2. **需求登记**：把每个需求登记清楚（来源、内容、期望时间、交付物）；
3. **任务派单**：按性质派给新媒体运营部、视觉传达部或创意设计部，并明确负责人与截止时间；
4. **进度跟进**：盯住关键节点，及时催办、协调资源；
5. **验收归档**：验收交付物，整理归档；
6. **会议组织与复盘**：组织例会与大型活动复盘。

## 三、标准作业流程（怎么办）

### 3.1 接单与登记

1. 接到需求后，填写《需求登记表》：需求方、需求内容、期望时间、交付形式；
2. 判断是否合理 / 可行，必要时与需求方确认细节；
3. 在 `01_时间表/` 中登记或更新该任务。

### 3.2 分类派单

| 需求类型 | 派给 | 备注 |
| --- | --- | --- |
| 文案、推送、排版 | 新媒体运营部 | 外派稿：对方给素材，新媒体排版；自有稿：新媒体自己写 |
| 摄影、摄像、视频号 | 视觉传达部 | 较大活动安排摄像 |
| 文创、展板、海报等视觉设计 | 创意设计部 | 相对独立，直接对接 |

1. 明确负责人、截止时间、交付物；
2. 派单后通知到人（群内 @ 或当面确认）。

### 3.3 跟进

1. 按日历 / 时间表在关键节点前 1 天提醒；
2. 遇到跨部门协作（如推送需要视觉配图），办公室主动撮合。

### 3.4 验收与归档

1. 对照需求确认交付物是否达标；
2. 交付物放入对应部门文件夹，重要材料归档；
3. 大型活动后 7 天内组织复盘。

## 四、与其他部门如何配合

| 对方 | 配合方式 |
| --- | --- |
| 新媒体运营部 | 外派稿先给办公室，由办公室派给新媒体；自有稿新媒体自行安排但需报备排期 |
| 视觉传达部 | 办公室把拍摄需求派给视觉；活动前发拍摄清单，活动后催收素材 |
| 创意设计部 | 办公室把设计需求（含 brief）派给创意；协调交付时间 |

## 七、常见问题（FAQ）

**Q：有人绕过办公室直接找新媒体做稿怎么办？**
A：先友好告知流程，补登记即可；紧急情况先做、事后补单，保证不耽误事。

**Q：派单后对方没按时完成？**
A：先提醒，再协调资源；反复超时的，在复盘会上提出改进办法（如明确工时、调整排期）。
