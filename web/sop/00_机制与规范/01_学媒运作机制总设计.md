# 学媒运作机制总设计

## 1. 设计目标

- **提效**：把重复性工作标准化，减少沟通与返工；
- **沉淀**：把流程、模板、规范固化下来，形成组织资产；
- **复用 + 创新**：标准流程保底，创作空间放开；
- **可协同**：四个部门共用一个时间表、一套日历、一个素材库，步调一致。

## 2. 总体思路：“五个一”

| 支柱 | 内容 | 对应位置 |
| --- | --- | --- |
| 一个盘子 | 内网云盘同步的项目根目录，唯一协作空间 | 本项目根目录 |
| 一套标准 | 流程、命名、模板、规范 | `00_机制与规范/` |
| 一个时钟 | 年度活动时间表（唯一数据源） | `01_时间表/schedule.csv` |
| 一套日历 | 各部门智能日历 + 全学媒总日历 | `02_总日历/`、各部门文件夹 |
| 一个知识库 | 素材库 + 指导培训 | `素材库/`、`培训与模板/` |

## 3. 任务全生命周期

```text
需求来源
  ├─ 学媒自有项目 ─────────────┐
  ├─ 外派（学支/学发/艺术中心）→ 办公室 → 需求登记 → 分类派单
                                                      │
         ┌────────────────┬───────────────┬─────────────┘
         ▼                ▼               ▼
     新媒体运营部       视觉传达部       创意设计部
   （文案/推送/排版）  （摄影/摄像/视频号）（文创/视觉设计）
         │                │               │
         └────────┬───────┴───────────────┘
                  ▼
           交付 → 验收 → 归档 → 复盘
```

## 4. 关键规则

1. **一个入口**：所有外派需求先到办公室，办公室统一登记、派单；不允许绕过办公室直接私下拉人（紧急情况事后补登记）。
2. **一个数据源**：所有活动与任务以 `01_时间表/schedule.csv` 为准，Excel 与日历都由它生成，避免多份表格不一致。
3. **素材先行**：视觉传达部在活动结束后 **48 小时内**把图 / 视频上传素材库；新媒体据此更新推送。
4. **提前预写**：新媒体对时效要求高的推送，**活动前预写文案**，活动后只换图 / 视频即可发布。
5. **标准 + 创新**：标准流程（任务登记、派单、命名、归档）必须遵守；文案、设计、拍摄内容鼓励创新。
