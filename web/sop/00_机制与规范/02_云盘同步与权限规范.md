# 云盘同步与权限规范

## 1. 方案选择

推荐优先使用书院已有的**内网共享盘 / NAS / 网盘**（如群晖、校园网盘、坚果云、OneDrive 等），任选其一作为唯一同步源。要求：

- 支持**文件夹级权限**；
- 支持**多设备同步**（电脑 + 手机）；
- 成员能“只读”查看素材和日历，部分目录可“编辑”。

> 若书院暂无统一网盘，可先用共享文件夹 + 定期备份过渡，待条件成熟再迁移。

## 3. 同步规则

1. **唯一数据源**：以云盘为唯一真相，本地修改后尽快同步；
2. **避免冲突**：同一文件同一时间只由一人编辑；多人协作用“另存新版本”；
3. **命名唯一**：文件 / 文件夹命名遵循 `03_素材库管理规范.md` 的命名规则；
4. **不乱建目录**：新目录须经办公室同意，避免结构混乱。

## 4. 备份

- 每学期末由办公室把整个项目打包备份一次（`归档/备份_YYYYMMDD.zip`）；
- 重要活动结束后 7 天内完成归档。
