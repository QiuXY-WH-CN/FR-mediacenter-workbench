# 时间表与任务流转规范

## 1. 时间表来源

- 唯一数据源：`01_时间表/schedule.csv`；
- 人读版本：`01_时间表/年度活动时间表.md`；
- 每年 8 月（秋季开学前）由办公室根据学校 / 书院校历更新一次，学期中动态微调。

## 2. `schedule.csv` 字段说明

| 字段 | 含义 | 示例 |
| --- | --- | --- |
| 部门 | 责任部门；`全学媒` 表示全员可见 | 新媒体运营部 |
| 活动名称 | 任务 / 活动名称 | 开学典礼推送 |
| 类别 | 任务类型 | 推送 / 拍摄 / 设计 / 对接 / 会议 |
| 开始日期 | YYYY-MM-DD | 2026-09-25 |
| 结束日期 | 可空；多日任务填结束日 | 2026-09-27 |
| 开始时间 | 可空；HH:MM | 19:00 |
| 结束时间 | 可空；HH:MM | 20:30 |
| 地点 | 可空 | 主楼报告厅 |
| 负责人 | 可空；填姓名 / 待定 | 待定 |
| 交付物 | 任务产出 | 推文链接 |
| 重复 | 可空；`每周` / `每两周` / `每月` | 每周 |
| 说明 | 备注 / 要求 | 活动前预写 |

## 3. 任务流转流程

```text
需求方 → 办公室（登记）→ 分类派单 → 责任部门执行 → 交付 → 办公室验收 → 归档 → 复盘
```

## 4. 状态定义

| 状态 | 含义 |
| --- | --- |
| 待确认 | 时间 / 需求尚未最终确定 |
| 已派单 | 已分配负责人 |
| 进行中 | 正在执行 |
| 已完成 | 已交付并通过验收 |
| 已归档 | 材料已归档 |

## 5. 日历生成

修改 `schedule.csv` 后，运行 `03_脚本/一键更新日历.bat`，会自动重新生成：

- 各部门 `部门_智能日历.ics`；
- `02_总日历/全学媒总日历.ics` 与 `全学媒总日历.html`。

成员重新导入 `.ics` 即可看到最新安排。
