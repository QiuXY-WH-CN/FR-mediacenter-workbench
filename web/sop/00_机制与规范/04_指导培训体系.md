# 指导培训体系

## 1. 目标

让新人快速上手，让老人持续精进，把个人经验变成团队资产。

## 2. 培训分层

| 层级 | 对象 | 内容 | 频次 |
| --- | --- | --- | --- |
| 新人入职培训 | 新成员 | 读手册、认部门、学工具、跟一次活动 | 招新后 1 周内 |
| 岗位技能培训 | 各部门 | 文案 / 排版 / 摄影 / 剪辑 / 设计专项 | 每学期 1–2 次 |
| 复盘会 | 全员 | 活动后复盘、问题与改进 | 每次大型活动后 |
| 传承交接 | 换届 | 文档、账号、素材、渠道交接 | 学年末 |

## 3. 新人上手清单

1. 读 `README.md` 与 `00_机制与规范/01_学媒运作机制总设计.md`；
2. 读本部门 `部门_部门手册.md`；
3. 打开本部门 `工作安排表.xlsx`，认领自己的任务；
4. 导入本部门 `智能日历.ics`；
5. 在学长 / 学姐带领下完整跟一次活动。

## 4. 模板清单（逐步补充）

| 模板 | 用途 | 位置 |
| --- | --- | --- |
| 需求登记表 | 办公室接单登记 | `培训与模板/` |
| 任务分派表 | 办公室派单 | `培训与模板/` |
| 推送排版模板 | 新媒体 | `培训与模板/推送模板/` |
| 海报 / 展板模板 | 创意 | `培训与模板/海报模板/`、`展板模板/` |
| 活动拍摄 checklist | 视觉 | 见本部门手册 |

## 5. 复盘机制

每次大型活动结束后 7 天内，办公室牵头开复盘会，产出**复盘记录**（`培训与模板/复盘/`），至少包含：做得好、待改进、下次行动。
