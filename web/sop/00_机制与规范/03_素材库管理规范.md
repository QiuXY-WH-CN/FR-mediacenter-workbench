# 素材库管理规范

素材库是新媒体做推送、创意做设计、各部门回顾活动的**公共资源池**。

## 1. 目录结构（建议）

```text
素材库/
├── 2026-2027学年/
│   ├── 20260925_开学典礼/
│   │   ├── 照片/        （精选照片，JPG，已压缩）
│   │   ├── 视频/        （成片 + 关键片段）
│   │   └── 源文件/      （原图/原始素材，体积大，仅视觉留存）
│   ├── 20261025_校庆日/
│   └── ...
└── 归档/
```

> 模板（推送模板、海报模板、展板模板）统一放在 `培训与模板/`，与原始素材分开。

## 2. 命名规范

- 活动文件夹：`日期_活动名`，例如 `20260925_开学典礼`；
- 文件：`日期_活动名_内容_序号`，例如 `20260925_开学典礼_主舞台_01.jpg`。

## 3. 上传时限与要求

| 内容 | 责任人 | 时限 | 要求 |
| --- | --- | --- | --- |
| 活动照片（精选） | 视觉传达部 | 活动后 **48 小时**内 | 精选可用图，去模糊 / 重复，按场景分文件夹 |
| 活动视频素材 | 视觉传达部 | 活动后 **72 小时**内 | 丰富素材，按机位 / 环节归类 |
| 推送配图 / 封面 | 视觉 / 创意 | 视推送排期（建议 24 小时内） | 符合平台尺寸 |
| 设计源文件 | 创意设计部 | 定稿后 3 天内 | 保留可编辑源文件 + 导出图 |

## 4. 使用规则

1. 新媒体做推送时，优先从素材库取图 / 视频，不再私下索要；
2. 使用他人素材需在推送末尾按平台惯例署名；
3. 原图 / 源文件默认只读，避免误删；精选素材允许被引用。

## 5. 存储与压缩

- 大文件（原始视频）可存云盘“源文件”目录，对外发布用压缩后的版本；
- 建议单张图片 < 5MB，视频按平台要求导出，避免云盘臃肿。
