# 冯如学媒 · 微信小程序

原生微信小程序，AppID 保留 `wx329dab0b8d30dec7`。账户、日历、任务、模板、积分和 SOP 均使用现有本机新版工作台的数据。此目录为可复现交付源，安装目标为 `C:\Users\QiuXY\WeChatProjects\miniprogram-1`。

## 当前运行方式

1. 运行网页项目 `../web/启动本地工作台.cmd`，地址仍为 `http://127.0.0.1:8766`。新版服务已加入 `/mini/api` 小程序入口。
2. 微信开发者工具打开 `miniprogram-1`，正常编译；保留项目已有私有配置中的开发域名免校验选项。使用原网页账号登录。
3. 连接设置默认“本机直连”。该地址只适用于同一台电脑的开发者工具，不适用于手机本身。
4. 若是手机同 Wi-Fi 联调，先停止原服务，再运行 `../web/启动局域网服务.cmd`；连接设置改为 `http://电脑局域网IP:8766`。仅在开发/调试环境中使用 HTTP；可能需要 Windows 防火墙允许 Node.js 的专用网络访问。

正式体验和跨网络使用请选择下面的云函数方式。电脑需要保持在线；不提供电脑关机后的云端业务副本。

## 功能

- 原生手机界面，亮橙/红/金辅助色与纯白背景；工作台、任务、日历、我的四个主入口。
- 空白日程、全天与起止时间、活动编辑和改期、云盘入口、任务添加和分工、交付依赖。
- 模板创建、编辑/复制、保存活动为模板、按模板创建并确认负责人和验收人。
- 接活、时间冲突、恢复接活、交付核对（点击/长按查看）、上传确认、验收/退回与积分。
- 手机日历和横向可滑动时间轴共用数据。手机改期通过活动编辑的日期选择器完成，避免滑动浏览时误改日期。
- 注册后由管理员审批开通；邀请码可指定部门与负责人角色并直接开通；支持成员角色、停用、密码修改与密码重置。
- SOP 知识库及积分明细；已有网页账户可在多个设备同时登录，退出只销毁当前会话；改密码或停用会撤销相关会话。
- 前台每 30 秒同步；进入页面、下拉刷新及保存修改时立即刷新。后台停止轮询，回来后立即同步。表单草稿不被轮询覆盖。

外部云盘链接采用复制到云盘客户端/浏览器访问。小程序不使用 web-view 强行打开任意第三方站点，不声称已自动上传或验证文件。

## 微信云服务：只做连接和身份

```text
微信小程序 → wx.cloud.callFunction → workbenchGateway 云函数
                                      ↓ HTTPS + HMAC 签名
电脑上的 /mini/api → 原业务 API → 本机 .local/preview.db
电脑网页 ────────────────────────┘
```

用户目前尚未创建云环境，也没有本机公网 HTTPS 地址。本项目已经提供云函数和签名校验，但不能在没有这两项配置时声称真实云链路已上线。

### 开通步骤

1. 在微信开发者工具中开通云开发环境，记下环境 ID。按实际套餐选择，由账号所有者确认云资源费用。
2. 为本机配置稳定 HTTPS 入口，转发到电脑的 `127.0.0.1:8766`。可用自有反向代理或受控内网穿透；云函数无法访问电脑的 `127.0.0.1` 或 `192.168.*`。
3. 生成至少 32 字符的随机桥接密钥。在 `../web/.local/mini-server.json` 写入 `{"appid":"wx329dab0b8d30dec7","bridgeSecret":"随机密钥"}`。重启本机服务。该文件不分发给小程序。
4. 在云函数环境变量设置 `MINI_APP_ID=wx329dab0b8d30dec7`、`LOCAL_API_ORIGIN=https://你的本机入口域名`、`BRIDGE_SECRET=同一个随机密钥`；函数超时建议 20 秒，并启用公网访问。
5. 右键 `cloudfunctions/workbenchGateway` → 上传并部署（云端安装依赖）。仅允许小程序调用，不要添加 HTTP/Web 触发器。源码固定使用官方示例中的 `wx-server-sdk 3.0.1`。
6. 小程序“我的 → 连接设置”选择微信云函数并输入环境 ID，测试连接。也可设置 `miniprogram/config.js` 的默认值后编译。
7. 先用学媒账号登录，在“我的”绑定微信；后续可使用“微信一键登录”。绑定以云函数可信 OPENID 为依据，本机保存散列身份映射；客户端不能自行传入身份进行绑定。

云端没有使用云数据库、存储或业务副本；请求转发过程中会临时经过云服务。云函数不输出账户密码和业务请求体到日志。正式使用还需要微信账号对应类目、隐私声明及平台发布条件，当前只交付开发项目。

## 多端同步与验证边界

- 共享的是当前 `../web/.local/preview.db`，没有复制一份独立小程序数据库。
- 小程序使用独立会话 token；网页仍使用 HttpOnly Cookie。浏览器同源保护保留；小程序不使用网页 Cookie，浏览器无法直接代持小程序存储中的会话 token。
- 云端请求 HMAC 签名包含时间、随机 nonce 和完整请求体；本机拒绝超时、重放和伪造身份。
- 云入口未配置时不会假装成功，也不会自动把数据切换到本地假数据。
- `scripts/test-mini.mjs` 位于网页项目中，使用隔离内存库检验多端登录、网页/小程序读写同步、退出、改密撤销、云签名和微信身份绑定。原业务测试继续可运行。
- 本交付同时进行微信自带 WXML/WXSS 编译检查。真实微信云调用及手机跨网络连接须配置云环境/HTTPS 后完成联调。
- 原生页面控制器已对接隔离内存服务完成创建活动、添加任务、接活、提交、验收、积分、模板保存和日历数据测试，并用微信编译后的 WXML 检查实际渲染数据与跳转参数。结果在交付源 `.qa/native-result.json`。
- 当前开发者工具服务端口关闭，尚未完成自动化模拟器/真机视觉验收。可在“设置 → 安全设置”开启服务端口后继续自动化验收；关闭状态不阻止用户手动编译和操作小程序。

## 源码与安装

`miniprogram/` 是原生前端，`cloudfunctions/workbenchGateway/` 是云函数。服务端改动位于网页项目的 `scripts/mini-gateway.mjs`、`scripts/dev.mjs` 和 `scripts/local-db.mjs`。

安装脚本 `node scripts/install.mjs` 只向已确认 AppID 的指定小程序项目复制交付文件，并先备份原空模板到本目录 `.backup/`。不会覆盖 `project.private.config.json`，也不会改动原来的 `quickstartFunctions` 云函数。
