# 冯如学媒协作工作台

面向校园学生媒体团队的协作工作台，提供网页端、微信小程序 / 多端应用，以及本地服务端。项目围绕“活动登记 → 任务派发 → 成果交付 → 验收归档”的 SOP 流程设计。

## 主要能力

- 活动与日程管理
- 任务派发、接单、时间冲突处理
- 成果提交与验收
- 素材库入口与交付确认
- 流程模板复用
- 积分与贡献排名
- SOP 知识库
- 管理员统计与成员权限管理
- 网页端与小程序 / 多端应用共享同一份数据

## 项目结构

```text
.
├── web/            网页端 + 本机服务端（含 /mini/api 小程序接口）
├── miniprogram/    小程序 / 多端应用源码
└── README.md
```

## 快速开始

### 网页端

```bash
cd web
pnpm install --frozen-lockfile
pnpm run build
pnpm run dev
```

打开 `http://127.0.0.1:8766/`。

### 小程序 / 多端应用

使用微信开发者工具打开 `miniprogram/` 目录，编译即可。详细说明见 `miniprogram/README.md`。

## 本地数据与隐私

- 本地业务数据保存在 `.local/`，默认不会提交到版本库。
- 请勿将 `.env`、`.local/preview.db`、云函数密钥或桥接密钥提交到公开仓库。
- 正式部署前请替换默认初始化口令和示例密钥。
