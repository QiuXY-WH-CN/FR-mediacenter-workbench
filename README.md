# 冯如学媒协作工作台

面向校园学生媒体团队的协作工作台。网页端、微信小程序与多端 APP 共用后端数据，围绕“活动登记 → 任务派发 → 成果交付 → 验收归档”协作。当前版本为 **v1.0.4**。

## 可以做什么

- 在全体协作与部门工作空间之间切换，查看对应日程和人员分配。
- 按“大任务 → 分任务”查看活动，任务按未完成、截止日期、优先级排序；高优先级项目集中显示在“急急急”。
- 使用日历与时间轴安排工作，接单、反馈冲突、提交成果、验收与归档。
- 在组织架构图中展开部门和成员；按权限管理账号、审核姓名与头像。
- 保存流程模板、查看素材入口与贡献记录、阅读 SOP 知识库。
- 在个人中心设置中文／English、85%—135% 字号、主题色、白／黑外观和高级粒子效果。界面语言不改写任务内容、成员姓名和“冯如学媒”品牌。
- 移动端通过底部“工作台、任务、日历、我的”导航；其他工作页面与账号操作归入“我的”。

## 启动网页端

需要 Node.js 24 或更高版本。首次安装依赖：

```powershell
cd web
pnpm install --frozen-lockfile
cd ..
```

在 Windows 双击根目录 `启动全部云服务.cmd`。脚本会构建资源、备份已有数据库、启动网页服务，并在已配置固定隧道时连接公网。本机地址为 `http://127.0.0.1:8766/`；当前固定公网地址为 [冯如学媒工作台](https://fengrumedia.dpdns.org/)。公网是否就绪以脚本的健康检查结果为准。

自动运行、不等待按回车：

```powershell
& './启动全部云服务.ps1' -NonInteractive
```

已运行的同工作区健康服务和固定隧道会被复用。修改代码后更新服务：

```powershell
& './web/scripts/restart-local.ps1'
```

旧启动器使用相对路径启动的实例需要首次明确核验其 PID，再执行 `restart-local.ps1 -ExpectedProcessId <已核验的旧服务 PID>`；不要填入其他进程的 PID。新启动器使用绝对路径，此后无需此参数。详细启动、日志与公网配置见 [服务端说明](web/README.md)。

使用微信开发者工具打开 `miniprogram/`，按 [多端说明](miniprogram/README.md) 编译。更新源码不会自动更新已安装的 APP 或已发布的小程序：APP 需要重新构建、安装，小程序需要另行上传和发布。本轮不上传微信小程序。

## 数据与隐私

业务数据库、备份、运行日志与本机状态保存在 `web/.local/`，不提交版本库。`.env`、隧道凭据和小程序云端密钥也应保留在本机或部署环境。未配置 `BOOTSTRAP_HASH` 时首管理员初始化被禁用，项目不提供公开默认初始化口令。

账号设置按账号保存，登录同一账号的其他端可刷新获取。鼠标与触控坐标仅参与本机粒子计算，不作为设置上传、不持久化、不写日志。分享仅提供小程序入口，不携带任务、成员资料、会话或邀请码。
